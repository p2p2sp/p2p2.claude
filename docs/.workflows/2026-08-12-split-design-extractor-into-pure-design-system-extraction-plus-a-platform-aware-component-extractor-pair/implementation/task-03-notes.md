- `checkScreenRefs` needed a raw `canonical:`-line counter (`rawCanonicalLines`, via `CANONICAL_LINE_RE` matched directly, not `canonicalRefs`) in addition to the `cited` set - the pre-existing fail-open backstop keyed off `cited.size === 0`, and once `canonicalRefs` drops `none`, a satellite whose every `## <slug>` block declares `canonical: none` (an all-gaps platform run) would have `cited.size === 0` and wrongly trip "carries spec content but cites no canonical screen" on every block. Counting raw `canonical:` lines (real or `none`) for the backstop decision, while still excluding `none` from `cited` (the set checked against `screens/`), satisfies criterion #3's "a `canonical: none` line yields no `missing-screen` finding" for this case too - not spelled out verbatim in the Approach text but required to actually deliver the stated criterion.
- CLI-level `--mode` tests write `REGISTRY_JSON` into its own sibling temp dir (`makeRegistry` helper) rather than inside the bundle dir under test - a `.json` file inside `BUNDLE_DIR` trips `checkForbidden` regardless of mode, and a real run always keeps `registry.json` at `<run>/`, never inside `<out>`.
