# Task 3 notes

- The header comment's new and changed passages (the cwd paragraph, the `root:` index entry, the commit bullet) are written in English while the rest of that header stays Polish, instead of the full English rewrite Task 2 did on `commit-task.sh`, because the Files line asks for a header comment covering this change only and the header is already mixed (the index and commit bullets were English before).
- Both `cd` calls carry a `CDPATH=` prefix, which Approach step 1 does not mention: with `CDPATH` set in the caller's environment, `cd` echoes the directory it moved to, and inside `plan_dir="$(cd ... && pwd)"` that echo would end up in the resolved plan path.
- The repository root is taken once into `repo_root` and reused for both the `cd` and the `root:` line, with a `-d` guard, so a repository with no working tree (a bare one, where `--show-toplevel` prints nothing) falls back to the cwd branch rather than moving nowhere and printing an empty value.
- Approach step 5 asks the test to compare `root:` with `slash(repo.dir)`; the assertion instead compares it with `git rev-parse --show-toplevel` run from the test itself (plus a check that it ends at the repository directory's own name and not at `/sub`), because git prints the physical path: macOS resolves `/var` to `/private/var` and Git-Bash's getcwd expands an 8.3 short name (`RUNNER~1`), so the raw Node temp path would differ from the script's output on the macOS and Windows CI legs while naming the same directory.
- Beyond the two new cases, the existing "outside a git repository" test gained one assertion that a `root:` line is present and non-empty, because the Edge cases name that fallback and nothing else covered it.
- UNDERSPECIFIED: the spelling of the `root:` value - neither the task nor the Contracts pin a normal form; decided it is verbatim what the environment gives (git's `--show-toplevel`, so `C:/...` under Git-Bash; plain `pwd`, so the MSYS `/c/...` form, outside a repository), with the consumer expected to hand it back to the same shell rather than to parse it.
