Shell commands that auto-run at specific lifecycle events like PostToolUse or Stop.
Why for you: Your worst recurring defect class is buggy_code (21 incidents) plus stray `</content>` tags and malformed generated files; a PostToolUse hook can catch these the instant a file is written instead of three review rounds later.
// .claude/settings.json { "hooks": { "PostToolUse": [ { "matcher": "Write|Edit", "hooks": [ { "type": "command", "command": "f=\"$CLAUDE_TOOL_FILE_PATH\"; grep -l '</content>' \"$f\" && echo 'ERROR: stray </content> tag written to '\"$f\" >&2 && exit 2; case \"$f\" in *.ts|*.tsx) npx prettier --write \"$f\" && npx tsc --noEmit ;; esac" } ] } ] } }
