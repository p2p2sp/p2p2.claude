## Task 4 — feat(superui): extend preview lint to data files and rework index toggle

- `build_index.py`'s summary counters (`nf`/`nc`/`np_`) switched from `t.startswith("foundations"/"components"/"patterns")` to a trailing-slash variant (`"components/"` etc.) — required because `targets` now also carries the bare `"components.js"` self-verification entry, and `"components.js".startswith("components")` would have double-counted it as a component sheet. Not in the Approach text but necessary to keep the summary line accurate; no behavior change for existing subdir targets (they already contain a `/`).
- `sheet_title()` decodes the data file's `"title"` JSON string via `json.loads('"' + group + '"')` (with a fallback to the raw captured text on a `ValueError`) rather than a plain string slice, so any JSON escape in a title (e.g. `\"`) round-trips correctly instead of leaking a backslash into the link label. Minor robustness addition consistent with the Approach's intent ("title" source), not a deviation from it.
