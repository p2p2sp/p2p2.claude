# GitHub

superdev pomaga domknąć pracę po stronie GitHuba: opisać zgłoszenie, zatwierdzić zmiany commitem i
przygotować pull request — w ramach tej samej rozmowy z Claude.

## Co możesz zrobić

| Zadanie | Jak poprosić |
|---------|--------------|
| **Utworzyć zgłoszenie (issue)** | Opisz problem lub potrzebę i poproś o założenie zgłoszenia na GitHubie. |
| **Zatwierdzić zmiany commitem** | Poproś o commit; superdev przygotuje czytelny opis na podstawie wprowadzonych zmian. |
| **Przygotować pull request** | Po wdrożeniu poproś o pull request — powstanie wraz z opisem podsumowującym pracę. |

## Naturalne połączenia

Te czynności łączą się z głównym tokiem pracy. Plan zmiany może prowadzić do zgłoszenia, a ukończone
wdrożenie — do pull requesta. Nie musisz przełączać narzędzi; opisujesz kolejny krok, a superdev go
wykonuje.

## Wymagania

Do operacji na GitHubie potrzebny jest skonfigurowany dostęp (zalogowane narzędzie wiersza poleceń
GitHuba). Jeśli czegoś brakuje, Claude poinformuje, co trzeba uzupełnić.
