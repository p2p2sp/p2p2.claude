# superdev

superdev to ekosystem wytwarzania oprogramowania. Prowadzi Cię od pomysłu na zmianę, przez plan i jej
wdrożenie, aż po pamięć projektu, dokumentację i pracę z GitHubem — bez wychodzenia z rozmowy z Claude.

## W tym dziale

- **[Planowanie i implementacja](./planowanie-i-implementacja.md)** — główny tok pracy: od opisu
  zmiany, przez plan do zatwierdzenia, po wdrożenie krok po kroku.
- **[Pamięć projektu](./pamiec-projektu.md)** — jak utrwalić wiedzę o projekcie, by Claude trzymał się
  Twoich konwencji.
- **[GitHub](./github.md)** — zgłoszenia, commity i pull requesty.
- **[Diagnostyka i specyfikacje](./diagnostyka.md)** — testy najpierw, debugowanie i specyfikacje
  techniczne.
- **[Dokumentacja użytkownika](./dokumentacja-uzytkownika.md)** — tworzenie pomocy dla osób
  korzystających z budowanego produktu.
