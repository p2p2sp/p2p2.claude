# superui

superui to ekosystem projektowy i frontendowy. Pozwala zbudować spójny system projektowy niezależny od
technologii, przełożyć go na konkretny framework, podejrzeć efekt w przeglądarce i bezpiecznie
wprowadzać zmiany w interfejsie.

## W tym dziale

- **[System projektowy](./system-projektowy.md)** — niezależny od frameworka opis tokenów, fundamentów
  i komponentów.
- **[Adaptacja do frameworka](./adaptacja-do-frameworka.md)** — przełożenie systemu na jedną docelową
  technologię.
- **[Podgląd UI](./podglad-ui.md)** — statyczny podgląd HTML bez kroku budowania.
- **[Strażnik edycji UI](./straznik-edycji-ui.md)** — wiąże zmiany interfejsu z udokumentowanym
  systemem.
- **[Publikacja artefaktu](./publikacja-artefaktu.md)** — udostępnienie pojedynczego pliku jako artefaktu
  Claude Code.

## Gdzie powstają pliki projektowe

System projektowy i jego adaptacje zapisywane są w katalogu `.superui/layout/` w Twoim projekcie.
