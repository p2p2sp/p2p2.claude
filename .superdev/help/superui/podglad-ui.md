# Podgląd UI

Podgląd pozwala zobaczyć efekt w przeglądarce jako statyczną stronę HTML — bez uruchamiania całego
projektu i bez kroku budowania.

## Po co to

- Szybko sprawdzasz, jak wygląda komponent lub ekran.
- Nie musisz konfigurować ani uruchamiać środowiska deweloperskiego.
- Widzisz wynik od razu, w zwykłej przeglądarce.

## Jak skorzystać

Poproś o podgląd elementu lub widoku, nad którym pracujesz. Powstaje samodzielna strona HTML, którą
otwierasz lokalnie.

## Czego się spodziewać

Podgląd jest statyczny — pokazuje wygląd, a nie pełne, działające zachowanie aplikacji. To narzędzie do
oceny warstwy wizualnej, nie do testów funkcjonalnych.
