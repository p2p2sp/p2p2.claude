# Pomoc: superdev + superui

superdev i superui to dwie wtyczki do Claude Code. Każda dodaje gotowy zestaw umiejętności, które
prowadzą Cię przez codzienną pracę — od planowania zmiany, przez jej wdrożenie, po dokumentację i
publikację. Pracujesz tak jak zwykle: opisujesz Claude, co chcesz osiągnąć, a właściwa umiejętność
włącza się sama.

## Którą wtyczkę wybrać

| Wtyczka | Do czego służy |
|---------|----------------|
| **superdev** | Wytwarzanie oprogramowania: pamięć projektu, planowanie, automatyczny tok wdrożenia zmiany i obsługa GitHuba. |
| **superui** | Projektowanie i frontend: system projektowy niezależny od frameworka, jego adaptacja do konkretnej technologii, podgląd UI i publikacja artefaktów. |

Wtyczki są od siebie niezależne. Możesz zainstalować jedną, drugą albo obie — żadna nie wymaga
drugiej do działania.

## Dla kogo jest ta pomoc

Dla osób, które używają tych wtyczek we własnych projektach: programistów i projektantów pracujących
z Claude Code. Nie musisz znać wewnętrznej budowy wtyczek — wystarczy, że wiesz, jaki cel chcesz
osiągnąć.

## Od czego zacząć

1. **[Pierwsze kroki](./pierwsze-kroki/README.md)** — instalacja, jednorazowa konfiguracja i zasada
   działania. Zacznij tutaj.
2. **[superdev](./superdev/README.md)** — planowanie i wdrażanie zmian, pamięć projektu, GitHub,
   diagnostyka.
3. **[superui](./superui/README.md)** — system projektowy, adaptacja do frameworka, podgląd UI,
   publikacja.
