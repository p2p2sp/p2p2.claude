A draft round carries its `work:` and `branch:` over, asking nothing. Otherwise, once `plan-index.sh` has passed, immediately for a draft:

- `Work: none` in the input writes `branch: none` and no `work:` key, asking nothing.
- Any other `Work: <entry key>` line asks nothing and writes that key into `work:`. The `branch:` key takes the `Branch:` line's name when the input carries one, without a report. Else run `"${CLAUDE_PLUGIN_ROOT}/scripts/plan-path.sh" --branch "<plan-path>"` and take that entry's `new:` value; an `error:` line ends this step: show it, record nothing. An entry whose `new:` reads `-`, or that no `entry:` line names, falls back to the question below.
- Without a `Work:` line, run that same report, an `error:` line ending this step likewise. Every `entry:` line reading `new: -` (no issue to number a name) writes `branch: none` and no `work:` key, asking nothing. Otherwise one `AskUserQuestion`: only when several `entry:` lines lack `new: -`, which entry, `suggested:` first, at most four, others by free text (else `suggested:`); then create that entry's `new:` from its `base:` - naming `base:` behind its remote when `behind:` is above 0, the tree dirty when `dirty: yes` would block the switch - stay on `current:` when not that `base:`, or no branch. Write the entry key into the frontmatter's `work:` key, the branch name or `none` into its `branch:` key.
