- No issue -> a returning draft carries `issue:` whose fetch failed: offer nothing and hand off. Otherwise run `"${CLAUDE_PLUGIN_ROOT}/scripts/issue-templates.sh"`. `STATUS=skip` -> state in one line why saving is impossible (`REASON=no-templates`: no issue form template; `no-gh`: GitHub command line tool missing; `no-repo`: no GitHub repository reachable), ask no save question, hand off. `STATUS=ready` -> ask through one `AskUserQuestion` whether to save the confirmed summary as a new GitHub issue. Yes -> save it per `${CLAUDE_PLUGIN_ROOT}/references/issue-save.md`, read at that step, with `directory: .temp/viber/intent/`, `eligible: non-bug` and `content:` the confirmed summary and the interview, then ask what next. No -> hand off.

What next: one `AskUserQuestion`, invoke the planner now or stop. Planner -> hand off. Stop -> name the issue URL, say `/viber:intent #<N>` resumes it and run nothing else; with no issue URL known, just stop.

A run tied to an issue, by its argument, its draft or a save, carries one line `Issue: <full issue URL>` inside the hand-off summary: the `URL=` value of `issue-facts.sh` or the `ISSUE_URL=` value of `issue-create.sh`, never anything else.
